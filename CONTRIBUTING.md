# Contributing to RB Business Insights

Thank you for your interest in contributing to RB Business Insights! We welcome contributions that help improve our website, documentation, and resources.

## How to Contribute

### Reporting Issues
If you find a bug or have a suggestion for improvement:

1. Check if the issue already exists in our [Issues](https://github.com/rbbusinessinsights/rb-business-insights/issues)
2. If not, create a new issue with:
   - A clear title
   - Description of the problem or suggestion
   - Steps to reproduce (if applicable)
   - Screenshots or examples

### Submitting Changes

1. **Fork** the repository
2. **Create a branch** for your changes (`git checkout -b feature/your-feature-name`)
3. **Make your changes** following our guidelines (see below)
4. **Test your changes** thoroughly
5. **Commit** with clear messages (`git commit -m "Describe your change"`)
6. **Push** to your fork
7. **Submit a Pull Request** with a description of your changes

## Contribution Guidelines

### Code & Content Standards
- **HTML/CSS**: Follow existing code style and formatting
- **Content**: Use clear, professional language
- **Accessibility**: Ensure all changes are accessible (alt text for images, proper heading hierarchy)
- **Responsiveness**: Test changes on mobile, tablet, and desktop

### Before You Contribute
- Read our [README.md](./README.md) to understand the project
- Review our [LICENSE](./LICENSE)
- Check existing issues and pull requests

## Types of Contributions Welcome

- ✅ Bug fixes
- ✅ Content improvements
- ✅ Design enhancements
- ✅ Documentation updates
- ✅ Accessibility improvements
- ✅ Performance optimizations
- ✅ New resources or articles

## Code of Conduct

Please be respectful and professional in all interactions. We're committed to creating a welcoming environment for everyone.
