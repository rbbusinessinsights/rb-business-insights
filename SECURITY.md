# Security Policy

## Reporting Security Vulnerabilities

At RB Business Insights, we take security seriously. If you discover a security vulnerability in our website or codebase, please report it responsibly.

### Please DO NOT

❌ Open a public GitHub issue for security vulnerabilities  
❌ Post security vulnerabilities on social media  
❌ Publicly disclose the vulnerability until we've had time to fix it  

### Please DO

✅ Email your security concern to: [richard@rb-businessinsights.co.uk](mailto:richard@rb-businessinsights.co.uk)  
✅ Include details about the vulnerability  
✅ Provide steps to reproduce (if applicable)  
✅ Allow us reasonable time to respond and address the issue  

## What to Include in Your Report

- **Description**: What is the vulnerability?
- **Impact**: What could be affected?
- **Steps to Reproduce**: How can we verify it?
- **Suggested Fix** (if you have one): Optional
- **Contact Information**: How to reach you

## Our Response

We will:
1. Acknowledge receipt of your report within **48 hours**
2. Work to understand and verify the vulnerability
3. Develop and test a fix
4. Release a security update
5. Credit you in our security advisory (unless you prefer anonymity)

## Security Best Practices

When using our website or code:
- Keep your browser and software up to date
- Report any suspicious activity or potential vulnerabilities
- Respect privacy and data protection standards
- Follow responsible disclosure practices

## Scope

This security policy applies to:
- The RB Business Insights website
- Code in this repository
- Associated services and infrastructure
